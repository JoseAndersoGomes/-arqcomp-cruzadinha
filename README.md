# Omnitrix OS - Cruzadinha de Arquitetura Computacional

## Como Jogar

1. Clique em uma célula do tabuleiro e digite as letras da palavra. O foco avança automaticamente para a próxima casa.
2. Em células de cruzamento, clique novamente para alternar entre a digitação horizontal e a vertical. Use `Backspace` em uma casa vazia para voltar.
3. Clique em **Conferir** para validar as respostas: as palavras corretas ficam verdes e as incorretas, vermelhas.
4. Acompanhe o progresso no contador, que mostra `X de 12 palavras`. Ao acertar todas, aparece a mensagem de vitória.
5. Clique em **Reiniciar** para limpar o tabuleiro, o contador e a mensagem e começar de novo.

## Palavras e Pistas

| Palavra | Direção | Pista |
| --- | --- | --- |
| CPU | Vertical | Núcleo que busca, decodifica e executa instruções; o cérebro do Omnitrix. |
| ULA | Horizontal | Circuito que soma, subtrai e compara dados; a força bruta do DNA alienígena. |
| UC | Horizontal | Massa Cinzenta que sincroniza e comanda os sinais; o pulso do núcleo do relógio. |
| REGISTRADORES | Vertical | Posições ultrarrápidas dentro do chip, como aliens no banco do Omnitrix. |
| RAM | Vertical | Área volátil de trabalho lida e escrita pelo processador; perde tudo ao desligar. |
| ROM | Horizontal | Chip fixo que guarda instruções iniciais; o DNA original gravado pelo criador. |
| FLASH | Vertical | Armazenamento não volátil, apagável e regravável; o banco de DNA do Omnitrix. |
| CACHE | Vertical | Pequena memória veloz que copia dados usados com frequência; o atalho do Omnitrix. |
| MEMORIADEMASSA | Horizontal | Armazenamento secundário permanente, como discos e fitas; o cofre galáctico de DNA. |
| DMA | Vertical | Transferência entre periféricos e memória sem passar pelo núcleo; teletransporte de DNA. |
| DATABUS | Vertical | Canal compartilhado que transporta bits entre componentes; a corrente sanguínea do Omnitrix. |
| QUADCORE | Horizontal | Processador com várias unidades de execução no mesmo encapsulamento; time alienígena em um só corpo. |
